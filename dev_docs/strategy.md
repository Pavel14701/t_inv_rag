# Полная алгоритмическая стратегия "Структура + Импульс + Волатильность" (SIV)

**Тип:** Тренд-следующая с фильтрацией шума и входом по Smart Money.
**Таймфрейм:** Рекомендуемый H1 или D1 (для снижения шума).
**Активы:** Криптовалюты, Индексы (S&P 500), Крупные Акции.

---

## 🔍 Этап 0: Предварительная фильтрация (Окружение рынка)
*Прежде чем искать вход, мы проверяем, **стоит ли вообще торговать**.*

| Индикатор (группа) | Роль | Условие для входа (Лонг) | Условие для входа (Шорт) |
| :--- | :--- | :--- | :--- |
| **Entropy** (statistics) | Фильтр шума | Entropy < 0.65 (рынок структурирован, есть тренд) | Entropy < 0.65 (рынок структурирован) |
| **ADX** (trend) | Наличие тренда | ADX > 25 (тренд достаточно сильный) | ADX > 25 |
| **Z-Score** (statistics) | Аномалия | Z-Score > -1.5 (цена не экстремально низкая) | Z-Score < 1.5 (цена не экстремально высокая) |
| **AVSL/AVSR** (advanced) | Уровни | AVSL (поддержка) направлена вверх (бычий уклон) | AVSR (сопротивление) направлена вниз (медвежий уклон) |

*Если Entropy > 0.7 (рынок хаотичен) или ADX < 20 (флэт) — стратегия пропускает сделку!*

---

## 🌊 Этап 1: Определение глобального и локального тренда
*Мы не торгуем против "старшего" тренда.*

| Индикатор (группа) | Роль | Условие Лонг | Условие Шорт |
| :--- | :--- | :--- | :--- |
| **EMA 200** (overlap) | Глобальный тренд | Цена **выше** EMA 200 | Цена **ниже** EMA 200 |
| **OTT Direction** (ott) | Локальный тренд | OTT `direction == 1` (линия смотрит вверх) | OTT `direction == -1` (линия смотрит вниз) |
| **Ichimoku** (overlap) | Структура | Цена выше облака (Senkou Span) | Цена ниже облака (Senkou Span) |
| **Supertrend** (trend) | Стоп-тренд | Supertrend **зелёный** (цена сверху) | Supertrend **красный** (цена снизу) |

*Сигнал на вход рассматривается **ТОЛЬКО** если минимум 3 из 4 условий совпадают!*

---

## 📦 Этап 2: Поиск зоны входа (Smart Money / Order Blocks)
*Ищем, где крупный игрок оставил свои лимитные ордера.*

| Индикатор (группа) | Роль | Условие Лонг | Условие Шорт |
| :--- | :--- | :--- | :--- |
| **Order Block (Demand/Supply)** | Целевая зона | В окне виден **Demand Block** (зона покупателя) | В окне виден **Supply Block** (зона продавца) |
| **Pivots** (overlap) | Уровни | Demand Block совпадает с уровнем **Pivot Support** | Supply Block совпадает с уровнем **Pivot Resistance** |
| **Bollinger Bands** (volatility) | Перерастянутость | Цена находится у **нижней** полосы или пробила её (шорт-сквиз) | Цена находится у **верхней** полосы или пробила её (лонг-сквиз) |

*Идеальная ситуация: Цена подходит к нижней границе Demand Block (лонг) или к верхней Supply Block (шорт).*

---

## ⚡ Этап 3: Подтверждение импульса (Момент входа)
*Ждём, когда цена покажет "согласие" с нашим сценарием.*

| Индикатор (группа) | Роль | Условие Лонг | Условие Шорт |
| :--- | :--- | :--- | :--- |
| **RSI Clouds (RSI + MACD)** | Импульс | RSI > 30 (выход из перепроданности) **И** гистограмма MACD растёт (бычий кросс) | RSI < 70 (выход из перекупленности) **И** гистограмма MACD падает (медвежий кросс) |
| **Stochastic RSI** (momentum) | Ранний сигнал | %K пересекает %D **снизу вверх** в зоне < 20 | %K пересекает %D **сверху вниз** в зоне > 80 |
| **CCI** (momentum) | Экстремум | CCI > -100 и начинает разворачиваться вверх | CCI < 100 и начинает разворачиваться вниз |
| **Свечной паттерн** (cdl_*) | Триггер (вход) | **Bullish Engulfing** ИЛИ **Morning Star** ИЛИ **Hammer** (в зоне блока) | **Bearish Engulfing** ИЛИ **Evening Star** ИЛИ **Shooting Star** (в зоне блока) |

*💡 Важно: Вход происходит ТОЛЬКО когда появился свечной паттерн (например, Поглощение) **внутри зоны Order Block**.*

---

## 📊 Этап 4: Управление рисками (Размер позиции и Стопы)
*Без этого пункта любая стратегия превращается в лотерею.*

| Индикатор (группа) | Роль | Вычисление |
| :--- | :--- | :--- |
| **ATR** (volatility) | Расчёт стопа | Стоп-лосс = **1.5 × ATR(14)** от цены входа. (Для крипты 2× ATR) |
| **MAD / StDev** (statistics) | Расчёт цели (Тейк) | Тейк-профит 1 = **2 × ATR** (соотношение Риск/Прибыль 1:1.3). <br> Тейк-профит 2 = **3 × ATR** (Риск/Прибыль 1:2). |
| **AVSL/AVSR** | Динамическая цель | Тейк-профит также устанавливается на уровне **AVSR** (для лонга) или **AVSL** (для шорта), если они ближе, чем 2×ATR. |
| **Volume** | Подтверждение стопа | Если объём на свече входа > среднего за 20 периодов (Avg Vol) — сделка надежнее, стоп можно сдвинуть к 1× ATR. |

**Формула размера позиции:**
```python
RiskCapital = (Капитал * 1%) / (Стоп_лосс_в_пунктах)
```
*Пример: Риск на сделку = 1% от депозита.*

## 📋 Полный алгоритм действий (Пошагово)

Чтобы войти в **ЛОНГ**, система должна последовательно (сверху вниз) получить "ЗЕЛЕНЫЙ" свет на всех уровнях:

1. **Окружение:** Entropy < 0.65, ADX > 25, Z-Score не экстремален, AVSL направлена вверх. ✅
2. **Тренд:** Цена выше EMA 200, OTT направлен вверх (1), Supertrend зеленый. ✅
3. **Зона:** Цена находится внутри Demand Order Block (или касается нижней границы Bollinger). ✅
4. **Импульс:** Гистограмма MACD растет, Stochastic RSI пересек вверх, появилась бычья свеча "Поглощение". ✅
5. **Вход:** Открываем позицию по цене **Close** этой свечи (или Market на следующей свече).
6. **Стоп:** Выставляем на `Entry - 1.5 * ATR(14)`.
7. **Тейк 1:** Выставляем на `Entry + 2 * ATR(14)` (закрываем 50% позиции).
8. **Тейк 2 (трейлинг):** Для оставшейся части активируем трейлинг-стоп по **Supertrend** (как только Supertrend становится красным — закрываем остаток).

## 🔧 Пример конфига для Python (Псевдо-код)

```python
def check_long_signal(df, idx, order_blocks):
    # Уровень 0
    if entropy[idx] > 0.65 or adx[idx] < 25: return False
    if zscore[idx] < -2.0: return False  # слишком рискованно
    
    # Уровень 1
    if not (close[idx] > ema_200[idx] and ott_dir[idx] == 1 and supertrend_color[idx] == 'green'):
        return False
        
    # Уровень 2
    current_ob = get_order_block_at_price(price=close[idx], blocks=order_blocks)
    if not current_ob or current_ob.type != 'demand': return False
    if not (bb_low[idx] <= close[idx] <= bb_mid[idx]): return False # в нижней половине
    
    # Уровень 3 (поиск паттерна на idx или idx-1)
    if not (is_bullish_engulfing(df, idx) or is_hammer(df, idx)): return False
    if not (rsi[idx] > 30 and macd_hist[idx] > macd_hist[idx-1]): return False
    
    # Уровень 4 (Риск)
    atr_val = atr[idx]
    stop = close[idx] - 1.5 * atr_val
    tp1 = close[idx] + 2.0 * atr_val
    
    return {'entry': close[idx], 'stop': stop, 'tp': tp1}
```
